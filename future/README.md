# 미래 의식주 생활문화 탐구실 (`future/`)

고1 기술·가정 Ⅰ. 생활 문화와 디지털 환경(03 미래의 건강한 먹을거리 · 04 미래의 지속가능한 입을 거리 · 05 미래의 안전한 보금자리) 수업용 학생 웹앱입니다.
**기후 변화를 여러 변화 요소 가운데 하나**로 두고, 미래 기술이 의·식·주 생활문화를 어떻게 바꿀지 종합적으로 탐구합니다.

- 학생 주소: https://hahahoho-2.github.io/climate-living-lab/future/
- 교사용 안내(차시 계획·평가 기준·내용 검증표·주의할 표현): https://hahahoho-2.github.io/climate-living-lab/future/teacher.html
- 로그인·서버 없음. 학생 기록은 그 기기의 브라우저에만 저장됩니다(저장 이름 `futureLab.v1.` — 기존 탐구실 기록과 섞이지 않음).

## 학생 활동 흐름

| 탭 | 하는 일 |
|---|---|
| ① 변화 읽기 | 변화 요소 5가지(기후 변화 · 인구·가족 구조 · 디지털 전환 · 자원·환경 · 가치·소비 욕구)를 자료로 읽고, 내 생활에 미칠 영향을 한 문장으로 씁니다. 기후 변화는 기상청 전망 그래프(폭염일수·열대야일수)로 확인합니다. |
| ② 기술 탐색 | 식(스마트팜·식물성 대체식품·식용 곤충·배양육·푸드테크·HMR과 저탄소 식생활), 의(스마트 의류·웨어러블 헬스케어·메타 패션·3D 프린팅 의류·순환 패션), 주(스마트 홈·홈 네트워크 보안·3D 프린팅 건축·제로에너지 건축·유니버설 디자인) 기술 카드 16개. 카드마다 ‘무엇인가 → 어떻게 작동하나 → 지금 어디까지 → 기대·한계 → 아직 단정할 수 없는 것’. 실험실: 식품 1kg당 온실가스 그래프, 센서 규칙 만들기, 무선 통신 고르기, 다중 인증 판별기. 분야마다 ‘전통에서 배우기’(발효·한복·한옥). |
| ③ 사실·주장 가려내기 | 문장 14개를 ‘맞는 설명 / 틀리거나 과장 / 아직 단정할 수 없음’으로 판단하고 근거·출처를 확인합니다. |
| ④ 미래 생활 설계 | 가상 인물과 시기를 고르고, 변화 요소 2개 이상과 의·식·주 기술(또는 생활 실천)을 엮어 장면·근거·걱정과 대안을 씁니다. 미래의 하루, 다섯 렌즈(안전·보안·개인정보 / 건강 / 환경 / 형평성 / 문화) 점검. |
| ⑤ 보고서 | 점검표, 미리보기·인쇄(PDF), Word(.doc) 저장, 글 복사. |

## 내용 정확성 원칙

- 모든 사실 문장은 출처와 대조했습니다(확인일은 `content.js`의 `CHECKED`). 출처 목록은 `content.js`의 `sources`.
- 기후 수치는 이 폴더에 쓰지 않고 `../data.js`(기상청 기후정보포털, 2026-10-15 조회)를 그대로 읽습니다.
- ‘완전식품’, ‘절대 안전’, ‘해결되었다’처럼 근거보다 강한 표현은 쓰지 않고, 연구 결과가 엇갈리는 내용은 ‘아직 단정할 수 없는 것’으로 따로 표시했습니다.
- 교과서·슬라이드 자료에서 주의할 표현과 바꿔 쓸 표현은 `teacher.html` 7절에 정리했습니다.

## 고치는 방법

- 내용(변화 요소·기술 카드·사실·주장 문장·출처·인물): `content.js` 한 파일. 수치를 고치면 출처와 `CHECKED`도 함께 고쳐 주세요.
- 화면 동작: `app.js` · 모양: `future.css`(공통 모양은 `../style.css`).
- 오프라인 백업: 바탕 폴더의 `오프라인백업_다시만들기.ps1`을 실행하면 `미래생활문화_탐구실_오프라인.html`도 함께 새로 만들어집니다.
