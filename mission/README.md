# 기후 적응 디자인 의뢰소 (시험판)

기존 판(`../`)의 ②·③ 단계를 **가상 의뢰인의 의뢰를 해결하는 미션**으로 바꾼 시험판입니다.
기존 판의 파일은 하나도 고치지 않았고, 이 `mission/` 폴더만 새로 추가했습니다.

| | 기존 판 | 디자인 의뢰소 시험판 |
|---|---|---|
| 주소 | `/climate-living-lab/` | `/climate-living-lab/mission/` |
| ① 기후 예측 | 같음 | 같음 (같은 코드) |
| ② | 의·식·주 탐구 (궁금증 질문·데이터 가설·탐색 카드·설계 카드) | **디자인 의뢰소** (미션 1~4) |
| ③ | 탐구 보고서 | **디자인 제안서** + 품질 코치 |
| ④ 나만의 웹 · ⑤ 자료 찾기 | 같음 | 같음 (② 기록을 자동으로 가져옴) |
| 기록 저장 | `climateLab.v1.` | `climateLab.m1.` (서로 섞이지 않음) |

## 학생 활동 흐름 (② 디자인 의뢰소)

1. **📨 미션 1 · 의뢰 받기** — 의·식·주 중 한 분야와 가상 의뢰인(분야마다 2명)을 고릅니다.
   지역·시나리오·대비할 기간을 정하면 그 분야에 중요한 지표 3개가 ‘기후 브리핑’으로 나옵니다.
   ‘숫자 실감’은 기상청 수치를 단순 계산(1년 중 %, 몇 배, 몇 달 치, 증가율)으로만 바꿔 보여 줍니다.
2. **🧩 미션 2 · 단서 보드** — 단서 5칸을 채웁니다.
   - 기후 단서 2개: 데이터 카드나 ①에서 📌 담은 근거 중에서 고릅니다. 지역·시나리오·기간·단위가 자동으로 붙습니다.
   - 조사 단서 1개: 학생이 확인한 사실과 **출처**를 함께 써야 칸이 채워집니다. 탐색 카드에서 가져와 출발점으로 쓸 수 있습니다.
   - 의뢰인 단서 1개: 의뢰인의 조건 중 1~2개를 고릅니다.
   - 탐구 질문 1개.
3. **⚔️ 미션 3 · 아이디어 대결** — 아이디어 3개를 내고, 5개 기준(기후 대응 효과·의뢰 조건·사용자 편의·안전·비용·에너지·환경)으로 1~3점을 매깁니다.
   점수가 가장 높지 않아도 이유를 설명할 수 있으면 다른 아이디어를 골라도 됩니다. 📊 표시 아이디어는 rules.js 규칙이 지금 기후 자료에서 ‘해당’으로 판단한 것입니다.
4. **🥊 미션 4 · 도전장** — 최종 아이디어에 맞는 반론 질문 2장을 받아 근거를 들어 답하고, 보완점을 적습니다. 다른 도전장으로 2번까지 바꿀 수 있습니다.

미션을 마칠 때마다 ⭐를 받고, 기록은 ③ 제안서에 자동으로 들어갑니다.

## ③ 디자인 제안서와 품질 코치

- 순서: 표지 → 의뢰 개요 → 기후 브리핑(자료표·기후 단서·① 예측) → 탐구 질문과 조사 → 아이디어 비교표 → 최종 제안 C-E-R-D → 도전과 보완·효과와 한계 → 동료 피드백·성찰 → 자기 점검.
- **품질 코치** 15개 항목이 빠진 것을 알려 주고, 누르면 그 자리로 이동합니다.
  예) 추론(R)에 기후 수치가 있는가, ‘그래서·때문에·따라서’ 같은 연결어가 있는가, 문장 틀의 빈칸(____)을 모두 채웠는가.
  품질 코치는 **형식만** 확인합니다. 내용이 맞는지는 동료 피드백과 선생님 확인이 필요합니다.
- 내보내기: 미리보기·인쇄(PDF), Word(.doc), 글 복사, 3분 발표 화면(의뢰와 기후 단서 → 아이디어 대결 → 최종 제안).

## 내용 정확성 원칙

- 기후 수치는 이 폴더 어디에도 직접 쓰지 않았습니다. 모두 `../data.js`(기상청 기후정보포털, 2026-10-15 조회)에서 읽습니다.
- 의뢰인은 모두 수업용 **가상 인물**이며 화면·제안서에 그렇게 표시됩니다.
- 도전장은 정답이 있는 문제가 아니라 학생이 근거를 들어 답해 볼 질문입니다.

## 고치는 방법

- 의뢰인, 비교 기준, 도전장: `missions.js`를 고칩니다. 도전장의 `keys` 낱말이 학생 아이디어 이름·설명에 들어 있으면 그 도전장이 먼저 나옵니다.
- 화면 모양: `mission.css`. 공통 모양은 `../style.css`를 함께 씁니다.
- ①·④·⑤는 기존 판과 같은 코드(`../js/sitegen.js`, `../js/webmaker.js`, `js/app.js`의 해당 부분)를 씁니다.

## 기존 판과 비교한 뒤 정하기

- **두 판을 함께 두기**: 이 폴더를 그대로 올리면 기존 주소는 그대로이고 `…/climate-living-lab/mission/`이 새로 생깁니다.
- **시험판으로 바꾸기**: 기존 판 첫 화면에서 시험판으로 가는 링크를 더하거나, 학생들에게 시험판 주소를 안내합니다.
- **쓰지 않기**: `mission/` 폴더를 지우면 됩니다. 기존 판에는 영향이 없습니다.
