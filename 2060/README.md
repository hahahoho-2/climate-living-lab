# 2060 생활 자료실 (`2060/`)

고1 기술·가정 공개수업 「미래 생활문화 탐색」에서 쓰는 학생용 자료 안내 웹사이트입니다.
미래 생활 양식의 변화를 유추하는 데 필요한 자료를 일곱 영역으로 모았고, 기후 자료 탐구실의 `자료 보기 → 내 예측 → 자료와 비교 → 생각 고치기` 과정을 모든 주제에 그대로 씁니다.

- 로그인·서버 없음. 학생 기록은 그 기기의 브라우저에만 저장됩니다(저장 이름 `life2060.v1`).
- 영역별 주소를 바로 열 수 있습니다. 예: `2060/#smart`, `2060/#bath`

## 영역

| 탭 | 주제 |
|---|---|
| ① 기후 예측 | 기후 전망(용인·서울, 5개 지표), 계절 길이 |
| ② 스마트 의류 | 심박수 재기, 건강 이상 감지, 정보·위치 전송 |
| ③ 스마트 홈 | 인증의 종류, 다중 인증, 생체 인증, IP카메라 해킹, 비밀번호 기준, 월패드와 망 분리 |
| ④ 미래 식생활 | 스마트팜, 푸드테크, 배양육, 곤충육, 3D 프린팅 식품 / 작물 지도, 쌀, 도시락, 배달, 밀키트 |
| ⑤ 미래 주거 | 패시브 주거, 옥상 흰색 칠하기, 단열재, 옥상정원, 모듈러 건축, 3D 건축 |
| ⑥ 공공재의 역할 | 공중전화, 목욕탕·찜질방, 영화관 관객과 분포, 공공도서관, 단지 안 여가, 혼자 사는 집 |
| ⑦ 미래 에너지 | 수소에너지, 소형모듈원자로, 연료전지 / 여름 전기 수요, 재생에너지 비중 |
| 자료 찾기 | 사이트별 찾는 순서, 다섯 가지 확인 질문, 해석 연습, 찾은 자료 기록 |
| 내 노트 | 예측과 자료 비교, 변화 사슬, 생각 추가하기, 글 복사 |

## 고치는 방법

- 내용(주제, 수치, 출처, 탭, 주제 순서): `content.js` 한 파일. 수치를 고치면 `src`도 함께 고쳐 주세요.
- 기후 수치는 `../data.js`를 그대로 읽습니다.
- 화면 동작: `app.js`, 모양: `lab.css`
- 주제 추가: `topics`에 넣고 `order`의 해당 탭에 id를 적습니다. `kind: "trend"`는 숫자 예측, `kind: "rows"`는 문항 예측입니다.

## 내용 원칙

- 자료 확인일은 `content.js`의 `CHECKED`입니다. 찾지 못한 값은 화면에 찾지 못했다고 적었습니다.
- 공공기관 통계, 회사 발표, 민간 조사, 언론 보도를 구분해 적었습니다.
- 단열재 열전도율은 민간 정리 자료입니다. 건강 이상 감지 규칙은 수업용으로 단순화한 예시입니다.
