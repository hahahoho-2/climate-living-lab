# 실시간 학급 광장 설정 안내 (선생님용)

반 코드만 넣으면 같은 반 친구들의 아바타가 학급 광장에 **바로** 나타나게 하는 기능이에요.
섬 코드를 복사해서 붙여 넣지 않아도 돼요.

- 설정하지 않으면 지금처럼 **섬 코드 방식**만 써요. 게임은 그대로 잘 돌아가요.
- 설정한 뒤에도 섬 코드 방식은 함께 쓸 수 있어요(백업, 다른 반 친구 초대 등).
- 서버는 구글 **Firebase 실시간 데이터베이스**(무료 Spark 요금제)를 써요.
- 게임 파일에 라이브러리를 더하지 않았어요. 지금처럼 `index.html`을 더블클릭해서 열면 돼요.

---

## 준비물

| 항목 | 내용 |
|---|---|
| 선생님 구글 계정 1개 | 학교 Google Workspace 계정은 관리자가 Firebase를 막아 두었을 수 있어요. 안 되면 개인 구글 계정을 써요. 계정에는 **2단계 인증**을 켜 두세요. |
| 학생 계정 | 필요 없어요. 학생 기기는 무작위 '익명 번호'로 자동 접속해요. |
| 요금 | **무료(Spark)**. 결제 카드가 없어서 요금이 나오지 않아요. **유료(Blaze)로 바꾸지 마세요.** |
| 걸리는 시간 | 15~20분 |

> Firebase 콘솔의 메뉴 이름은 조금씩 바뀔 수 있어요. 아래 이름과 다르면 비슷한 메뉴를 찾아 주세요.

---

## 1단계. Firebase 프로젝트 만들기

1. <https://console.firebase.google.com> 에 구글 계정으로 들어가요.
2. **프로젝트 만들기**를 눌러요.
   - 이름: 예) `yeoul-plaza`
   - Google 애널리틱스: **사용 안 함**(필요 없어요)
3. 만들어지면 화면 왼쪽 아래에 **Spark 요금제**라고 나오는지 확인해요.

## 2단계. 익명 로그인 켜기

1. 왼쪽 메뉴 **빌드 → Authentication** → **시작하기**.
2. **로그인 방법(Sign-in method)** 탭 → **익명(Anonymous)** → **사용 설정** → **저장**.

## 3단계. 실시간 데이터베이스 만들기 + 보안 규칙 붙여 넣기

1. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**.
2. 위치는 **싱가포르(asia-southeast1)** 를 권장해요. 한국에서 가장 가까워요.
3. 보안 규칙 시작 방식은 **잠금 모드**를 골라요. **테스트 모드는 고르지 마세요.**
4. **규칙** 탭을 열어요. 안에 있는 글을 모두 지우고, 이 폴더의 `firebase-rules.json` 내용을 그대로 붙여 넣어요. 그다음 **게시**를 눌러요.
   - 이 규칙이 학생 자료를 지키는 진짜 자물쇠예요. 꼭 게시해 주세요.
   - 게시할 때 오류가 나면 오류 문장을 그대로 알려 주세요.
5. **데이터** 탭 맨 위에 있는 주소를 복사해 둬요.
   - 예: `https://yeoul-plaza-default-rtdb.asia-southeast1.firebasedatabase.app`

## 4단계. 웹 앱을 등록해서 apiKey 받기

1. 왼쪽 위 **프로젝트 개요** 옆 톱니바퀴 → **프로젝트 설정** → **일반** 탭.
2. 아래쪽 **내 앱**에서 웹 아이콘(`</>`)을 눌러요.
   - 앱 닉네임은 아무거나 써요(예: `yeoul`).
   - Firebase Hosting은 체크하지 않아요.
   - **앱 등록**을 눌러요.
3. 화면에 나오는 `firebaseConfig`에서 `apiKey` 값(`AIza`로 시작)을 복사해요.
   - SDK를 설치하라는 안내는 무시해도 돼요. 이 게임은 라이브러리 없이 동작해요.

## 5단계. `js/live-config.js` 채우기

메모장으로 `js/live-config.js`를 열어요. 따옴표 안에 두 값을 붙여 넣고 저장해요.

```js
const LIVE_CONFIG = {
  apiKey: 'AIzaSy…(4단계에서 복사한 값)',
  databaseURL: 'https://yeoul-plaza-default-rtdb.asia-southeast1.firebasedatabase.app'
};
```

- 따옴표(`'`)와 쉼표(`,`)는 지우지 마세요.
- 이 두 값은 비밀번호가 아니에요. Firebase에서는 원래 공개되는 값이에요. 학생 자료를 지키는 것은 3단계의 보안 규칙이에요.
- 주소는 `firebaseio.com`이나 `firebasedatabase.app`으로 끝나는 Firebase 주소만 받아요. 다른 주소를 넣으면 실시간 광장이 켜지지 않아요.

### 온라인 주소(GitHub Pages)로 쓸 때
- 게임 주소: <https://hahahoho-2.github.io/climate-living-lab/rpg/>
- GitHub 저장소 <https://github.com/hahahoho-2/climate-living-lab> → `rpg` 폴더 → `js/live-config.js` → 연필(편집) 아이콘 → 두 값을 붙여 넣기 → **Commit changes**.
  - 1~2분 뒤 온라인 주소에 반영돼요.
  - 학생은 주소 하나만 열면 돼요. 폴더를 나눠 줄 필요가 없어요.
- 공개 저장소에 `apiKey`를 올리면 GitHub나 Google에서 "키가 공개됐다"는 알림 메일이 올 수 있어요. Firebase 웹 키는 원래 공개되는 값이라 괜찮아요.
  - 더 안전하게 하려면(선택): Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보 → 해당 API 키 → **애플리케이션 제한사항: 웹사이트** → `https://hahahoho-2.github.io/*`를 넣어요.
  - 이렇게 하면 다른 사이트에서는 이 키를 못 써요. 대신 폴더를 더블클릭해서 연 게임에서는 실시간 광장이 안 돼요.
- Claude 페이지(claude.ai에 게시한 페이지)에서는 바깥 서버 연결이 막혀 있어서 실시간 광장이 동작하지 않아요.

## 6단계. 연결 시험하기(선생님 컴퓨터)

1. `index.html`을 더블클릭해요.
2. 처음 화면 **🎪 학급 광장** → 오른쪽 **🛰️ 실시간 반 광장**에 반 코드를 넣어요(예: `test-1234`). 그다음 **들어가기**를 눌러요.
3. **"연결됨"** 이 나오면 성공이에요. 내 섬이 없는 기기에서는 "구경만 해요"라고 나와요. 선생님 화면을 칠판에 띄울 때 이렇게 쓰면 돼요.
4. 학생 두 명처럼 시험하려면 **다른 브라우저**(예: 크롬과 엣지)나 **다른 기기**를 써요.
   - 같은 브라우저의 두 탭은 저장 공간을 같이 써서 같은 학생으로 취급돼요.

연결이 안 되면 화면 메시지를 보고 아래를 확인해요.

| 화면 메시지 | 확인할 곳 |
|---|---|
| 설정이 덜 됐어요(익명 로그인) | 2단계: 익명 로그인 사용 설정 |
| 설정이 맞지 않아요(API 키) | 4·5단계: `apiKey`를 잘못 복사하지 않았는지 |
| 주소를 찾지 못했어요(databaseURL) | 3단계 5번 주소를 그대로 넣었는지 |
| 반 광장에 들어갈 수 없어요(보안 규칙) | 3단계 4번 규칙을 **게시**했는지, 반 코드 형식이 맞는지 |
| 인터넷 연결이 끊겼어요 | 학교 인터넷이나 방화벽이 `firebasedatabase.app`, `googleapis.com`을 막지 않았는지 |
| 지금 들어오는 친구가 많아요 | 잠시 기다리면 저절로 다시 연결해요(아래 '알아 두면 좋은 점' 참고) |

설정을 고친 뒤에는 **다시 연결** 버튼을 눌러요.

### (선택) 규칙 시뮬레이터로 규칙 확인하기
Realtime Database → **규칙** 탭 → **규칙 플레이그라운드**(시뮬레이터)에서 아래처럼 확인할 수 있어요.

| 시험 | 위치 | 인증 | 기대 결과 |
|---|---|---|---|
| 읽기 | `/rooms/test-1234/residents` | 인증됨(익명) | 허용 |
| 읽기 | `/rooms` | 인증됨(익명) | 거부 |
| 읽기 | `/rooms/test-1234/residents` | 인증 안 됨 | 거부 |
| 쓰기 | `/rooms/test-1234/residents/abc` 에 `{"v":1,"n":"테스트","d":"{}","at":{".sv":"timestamp"}}` | 인증됨, UID `abc` | 허용 |
| 쓰기 | 같은 위치, 같은 자료 | 인증됨, UID `xyz` | 거부(남의 칸) |
| 쓰기 | `/rooms/TEST/residents/abc` | 인증됨, UID `abc` | 거부(반 코드 형식) |

## 7단계. 학생에게 나눠 주기

1. 5단계에서 고친 **폴더 전체**를 평소처럼 나눠 줘요(클래스룸, 압축 파일 등).
2. 반마다 **반 코드**를 정해 알려 줘요.
   - 영어 소문자, 숫자, `-`(빼기)로 4~24글자예요.
   - 다른 사람이 짐작하지 못하게 뒤에 아무 글자 4개를 붙여요.
   - 예: `yeoul-3-2-k7m2`
3. 학생이 할 일: 광장 → **🛰️ 실시간 반 광장** → 반 코드 → **들어가기**.
   - 한 번 넣으면 그 기기가 기억해요. 다음부터는 광장에 들어가기만 하면 저절로 연결돼요.

## 수업 중에 보이는 것

- 친구 아바타 이름표 왼쪽의 **초록 점**은 지금 접속 중이라는 뜻이에요(최근 2분 안에 신호가 온 친구). **회색 점**은 쉬는 중이에요. 쉬는 중인 친구도 광장에는 그대로 보여요.
- 학생이 광장을 떠나 마을로 가면 연결을 닫아요. 동시 접속 수를 아끼기 위해서예요. 다시 광장에 오면 저절로 연결되고, 그동안 바꾼 옷·식탁·집이 올라가요.
- 친구 카드에는 "실시간 반 광장 · 지금 접속 중/쉬는 중"이 표시돼요.

## 관리하기

| 하고 싶은 일 | 방법 |
|---|---|
| 장난 별명이나 이상한 아바타 내리기 | 콘솔 → Realtime Database → **데이터** → `rooms` → 반 코드 → `residents`. 칸마다 `n`에 별명이 보여요. 그 칸에서 휴지통을 눌러 지워요. 학생들 화면에서 바로 사라지고, 그 학생 화면에는 "아바타가 내려졌어요"가 떠요. |
| 학생이 내 화면에서만 안 보이게 하기 | 친구 카드 → **내 화면에서 숨기기**. 그 기기에서만 숨겨지고, **숨긴 친구 다시 보기**로 되돌릴 수 있어요. |
| 학생이 반 광장에서 나가기 | **반 광장에서 나가기**를 누르면 친구들 광장에서 내 아바타가 지워져요. 내 섬 기록은 그대로예요. |
| 학기 끝 정리 | 콘솔 → 데이터 → `rooms` 아래 반 코드 칸을 통째로 지워요. |
| 사용량 확인 | 콘솔 → Realtime Database → **사용량** 탭 |

- 무료 요금제는 **동시 접속 100개**까지예요. 한 반 30명이면 같은 시간에 3개 반 정도까지 쓸 수 있어요(선생님 화면도 1개로 세요).
- 무료 한도를 넘으면 그 달은 실시간 광장이 멈춰요. 돈은 나가지 않고, 섬 코드 방식은 계속 쓸 수 있어요.

## 무엇이 올라가고, 누가 볼 수 있나요

- **올라가는 것**: 별명, 몸 색, 동물 친구, 고른 지역·미래, 시대·날짜, 옷(옷장 포함), 식탁, 집, 수확·요리 횟수, 마지막 접속 시각.
- **올라가지 않는 것**: 실명, 연락처, 가방·밭 기록, 퀴즈 기록.
- **볼 수 있는 사람**: 게임 파일과 그 반 코드를 가진 사람. 반 목록 전체는 아무도 볼 수 없어요.
- **학생 기기에 저장되는 것**: 무작위 익명 번호와 그 로그인 열쇠, 반 코드, 숨긴 친구 목록뿐이에요.
- **받은 자료가 거치는 세 겹**:
  1. 서버 규칙: 자기 칸에만, 정해진 모양과 크기로만 쓸 수 있어요.
  2. 받을 때 다듬기: 섬 코드와 같은 다듬기를 거쳐 게임에 있는 값만 남겨요.
  3. 화면 글자 처리: 모든 글자를 '그냥 글자'로 바꿔서 보여 줘요.
- **저장 위치**: 구글 서버(3단계에서 고른 지역). 접속할 때 IP 주소는 구글이 처리해요. 학교 개인정보 지침이 있으면 확인해 주세요.

## 알아 두면 좋은 점(한계)

- 학생이 개발자 도구로 자기 자료를 꾸며 올릴 수는 있어요. 하지만 다듬기를 거쳐 게임에 있는 값만 보여요. 별명을 친구와 똑같이 지을 수도 있어요. 이럴 때는 콘솔에서 그 칸을 지워 주세요.
- 다른 친구의 섬을 흉내 낸 자료로 **접속 중인 친구를 가릴 수는 없어요.** 다만 쉬는 중인 친구의 오래된 아바타 자리에 대신 보일 수는 있어요.
- 재부팅하면 초기화되는 컴퓨터실처럼 기기 저장 공간이 지워지는 곳에서는, 학생이 다시 들어올 때마다 새 익명 번호가 생겨요.
  - 같은 섬이면 광장에는 하나로 모아 보여 줘요. 다만 새 번호가 생긴 뒤 2분 동안은 두 번 보일 수 있어요.
  - 지난 칸은 콘솔에 남아요. 학기 끝에 반 칸을 통째로 지워 주세요.
- Firebase는 같은 인터넷 주소에서 **새 익명 번호를 1시간에 100개까지** 만들어 줘요. 학교 전체가 같은 주소를 쓰고 처음 접속하는 기기가 한꺼번에 100대를 넘으면 "잠시 뒤에 다시 연결할게요"가 뜰 수 있어요. 한 번 접속한 기기는 번호를 기억해서 다시 만들지 않아요.
- 실시간으로 함께 움직이는 것은 '누가 광장에 있는지'와 '아바타·섬 자료'예요. 광장 안에서 걸어 다니는 위치는 기기마다 따로 움직여요.

## 파일

| 파일 | 내용 |
|---|---|
| `js/live-config.js` | 선생님이 채우는 설정(apiKey, databaseURL). 비어 있으면 실시간 광장이 꺼져요. |
| `js/live.js` | 실시간 광장 동작(익명 로그인, 올리기, 실시간 받기, 접속 표시) |
| `firebase-rules.json` | Firebase 콘솔에 붙여 넣는 보안 규칙 |
| `js/plaza.js` | 광장 화면. 실시간 친구와 섬 코드 친구를 함께 보여 줘요. |
