# 미래 기후 대비 · 여울섬 기후 생활 RPG (1판)

미래 기후에 대비한 **의식주(먹거리·옷·집)** 를 준비하는 생활문화 탐색 RPG예요.
학생은 새싹이 캐릭터와 동물 친구를 데리고 여울섬 마을을 돌아다니며 주민과 이야기하고,
밭을 가꾸고, 식탁을 차리고, 옷장을 채우고, 집을 지어요. 그리고 2030년대 → 2050년대 → 2090년대 여름을 살아 봐요.

## 바로 하기 (온라인)
- 게임: **https://hahahoho-2.github.io/climate-living-lab/rpg/**
- 자동 시험: https://hahahoho-2.github.io/climate-living-lab/rpg/tests/test.html
- 같은 저장소의 「미래 기후와 의식주 탐구실」: https://hahahoho-2.github.io/climate-living-lab/ (이 게임 파일은 저장소의 `rpg/` 폴더에 있어요)
- 학생에게는 게임 주소 하나만 알려 주면 돼요. 섬 기록은 학생 기기의 브라우저에 저장돼요.

## 학급 광장 확인하는 방법
| 방법 | 준비 | 학생이 할 일 | 선생님이 확인하는 법 |
|---|---|---|---|
| 섬 코드 (지금 바로) | 없음 | 「내 섬 코드 만들기」 → 복사해서 학급 게시판(클래스룸·패들렛)에 올리기 | 게시판의 코드를 모두 복사 → 게임 처음 화면 「🎪 학급 광장」 → 붙여 넣고 「광장에 초대하기」 → 「📊 우리 반 비교표」 |
| 실시간 반 광장 | Firebase 설정 15~20분(`실시간광장_안내.md`) 후 `js/live-config.js` 채우기 | 광장에서 반 코드 넣기(한 번만) | 처음 화면 「🎪 학급 광장」 → 같은 반 코드 → 학생 아바타가 바로 모여요(칠판 화면에 띄우기 좋아요) |

- 실시간 반 광장은 위 온라인 주소(GitHub Pages)와 폴더 더블클릭 모두에서 동작해요. 설정은 GitHub에서 `rpg/js/live-config.js`를 고쳐 저장(커밋)하면 1~2분 뒤 사이트에 반영돼요.
- Claude 페이지(claude.ai 게시)에서는 바깥 서버 연결이 막혀 있어서 실시간 반 광장이 동작하지 않아요. 섬 코드 방식만 돼요.

## 여는 방법
- `index.html`을 더블클릭하면 바로 열려요. 서버나 설치가 필요 없어요.
- 인터넷이 없어도 돼요. 인터넷이 되면 둥근 제목 글꼴(Jua)만 추가로 불러와요.
- 태블릿(가로), 노트북, 크롬북에 맞춰 만들었어요. 휴대폰 세로 화면에서는 카메라가 주인공을 따라가요.

| 2 | 들깨 할머니 | 씨앗 심기, 물 주기, 차양·온실·볏짚 멀칭·두둑, 하루 보내기, 첫 수확 |

## 학급 광장 (친구 아바타 한곳에 모으기)
두 가지 방법이 있어요. 함께 써도 돼요.

### 실시간 반 광장 (선생님이 한 번 설정하면)
- 선생님이 Firebase(무료)를 설정하고 `js/live-config.js`를 채우면, 학생은 광장에서 **반 코드**만 넣으면 돼요. 같은 반 친구 아바타가 1초 안팎으로 바로 나타나요.
- 설정 방법·관리·개인정보는 **`실시간광장_안내.md`** 를 보세요. 보안 규칙은 `firebase-rules.json`이에요.
- `js/live-config.js`가 비어 있으면 실시간 광장은 꺼지고 아래 섬 코드 방식만 써요.

### 섬 코드 (서버 없이)
서버 없이 **섬 코드**로 나눠요.
1. 학생: 광장 게시판(또는 메뉴) → 「내 섬 코드 만들기」 → 복사하거나 .txt로 저장
2. 선생님: 학급 게시판(클래스룸, 패들렛 등)에 코드를 모아요.
3. 학생: 「학급 광장」 → 코드를 여러 개 한꺼번에 붙여 넣거나 .txt 파일 여러 개 불러오기
4. 광장에서 친구 아바타가 돌아다녀요. 누르면 친구의 옷·식탁·집과 점검 결과, 나와 비교한 내용을 보여 줘요. 「우리 반 비교표」로 반 전체를 한눈에 볼 수 있어요.

- 섬 코드에는 별명, 옷, 식탁, 집, 밭, 가방 기록만 들어가요. 실명·연락처는 들어가지 않아요(캐릭터 만들 때 별명을 쓰도록 안내해요).
- 섬 코드는 **백업**도 돼요. 다른 기기의 처음 화면에서 「섬 코드로 이어하기」를 하면 이어서 할 수 있어요.
- 받은 코드는 알 수 없는 값을 버리고 다듬어서 보여 줘요(이상한 글자·없는 아이템은 무시).

## 저장
- 이 기기의 브라우저에 자동 저장돼요(`yeoul-island-save-v1`). 광장 친구 목록은 `yeoul-plaza-v1`.
- 실시간 반 광장: 반 코드 `yeoul-live-room-v1`, 익명 번호 `yeoul-live-auth-v1`, 숨긴 친구 `yeoul-live-hidden-v1`.
- 2~3차시에 걸쳐 같은 기기로 이어 할 수 있어요. 기기가 바뀌면 섬 코드로 옮겨요.

## 내용 기준과 단순화
- 기후 자료: 기상청 경기도·서울특별시 기후변화 전망보고서(2023) 행정구역 평균, 기준 2000–2019 / 2021–2040 / 2041–2060 / 2081–2100, SSP1-2.6·SSP5-8.5.
- 폭염일: 하루 최고기온 33℃ 이상인 날. 열대야: 밤 최저기온 25℃ 이상인 날.
- 게임 날씨: 그 시대 폭염일수 ÷ 여름 92일을 '하루가 폭염일 확률'로 썼어요(최대 80%). 학습용 단순화이고 예보가 아니에요.
- 밭 규칙, 옷 점수(★), 집 점검은 모두 **비교를 위한 학습용 규칙**이라고 화면에 밝혀 두었어요.

## 시험하기
- 빌드 단계는 없어요(정적 웹). 고친 뒤에는 `tests/test.html`을 열어 **실패 0**인지 확인해요. 웹 서버(또는 온라인 주소)로 열면 파일 확인 2개까지 모두 해요.
- 명령줄에서: `chrome --headless=new --virtual-time-budget=15000 --dump-dom <주소>/tests/test.html` 결과의 `id="summary"`에서 통과·실패 수를 읽어요.
- 실시간 광장은 두 브라우저(또는 두 기기)로 같은 반 코드에 들어가 서로 보이는지 확인해요. 같은 브라우저의 두 탭은 같은 학생으로 취급돼요.
