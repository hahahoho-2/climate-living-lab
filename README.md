# 미래 기후와 의식주 탐구실 — 선생님용 안내

고1 기술·가정 「미래 기후와 의·식·주 생활문화」 수업에서 학생이 태블릿으로 쓰는 웹앱입니다.
학생은 **기후 자료를 확인해 미래 기후를 예측**하고, 그 근거로 **의·식·주 생활문화를 탐구·설계**합니다. 단계를 따라가면 **탐구 보고서**가 완성되고, 원하는 학생은 주제 하나를 골라 **나만의 탐구 웹**을 만들어 공유할 수 있어요.

- 로그인 없음 · 서버 없음 · 기후 자료가 앱 안에 들어 있어 한 번 열린 뒤에는 인터넷이 끊겨도 동작
- 학생 기록(예측·질문·보고서·나만의 웹)은 **그 기기의 브라우저에만** 저장되고 어디로도 전송되지 않음

## 1. 학생 활동 흐름 (탭 순서)

| 탭 | 학생 활동 | 수업 연결 |
|---|---|---|
| **① 기후 예측** | **1 자료 확인**: 시나리오(SSP1-2.6 저탄소 / SSP5-8.5 고탄소)와 기간(현재·전반기·중반기·후반기) 이해, 지표별 현재→전반기 변화 확인 → **2 예측하기**: 중반기·후반기 값을 −/+ 버튼으로 예측하고 근거 고르기(‘도움 받기’로 단순 추세 확인 가능) → **3 전망 비교**: 기상청 전망 공개, 내 예측과 차이, 시나리오 차이, 지역 비교, 전체 지표 한눈에 | 1차시 |
| **② 의식주 탐구** | 영역(식·의·주) 선택 → **❓ 궁금증 질문**(질문 틀·예시 질문, ⭐ 탐구 질문 정하고 답·출처 기록) → **📊 데이터로 가설**(기후 카드를 📌 근거로 담기, 기준을 넘으면 가설 등장) → **🔎 탐색 카드** → **✏️ 설계 카드** | 2차시 |
| **③ 탐구 보고서** | 활동보고서(docx)와 같은 순서로 자동 정리: 1 기후 자료 읽기 → 2 생활문화로 연결하기 → 3 주장·근거·추론·제안(C-E-R-D) → 4 피드백·성찰 → 5 자기 점검. 진행률 표시. **인쇄/PDF · Word(.doc) · 글 복사 · 3분 발표 화면** | 2~3차시 |
| **④ 나만의 웹** | 의·식·주 중 한 주제로 정보 웹페이지 만들기. 보고서 내용이 자동으로 채워지고, 구역(데이터·질문·아이디어·정보 카드·OX 퀴즈·자유 구역·참고 자료)을 켜고 끄며 수정 → 미리보기 → **공유 링크 / HTML 파일 / 코드 보기** | 심화·과제 |
| **⑤ 자료 찾기** | 기상청 포털 이용법, 우리 동네 등 다른 지역의 값을 **직접 입력** 또는 **CSV 불러오기**(5개 지표 모두 가능), 공식 자료 목록, 해석 주의점, 영화 《투모로우》 비교 질문 | 확장 |

### 영역별 탐색 카드

- **식생활 — 기후에 맞는 농작물 찾기**(서늘한 기후·따뜻한 기후·아열대 작물 14종) + **미래 메뉴 개발 카드**(대응할 기후, 조리법, 먹을 사람, 해결할 점, 재료)
- **의생활 — 섬유·소재 탐구**(천연·합성·재생·기능성 소재 12종, 흡습·건조·통기·보온·관리 비교표) + **기후 적응 의복 카드**(입는 때, 기후, 옷·소품, 소재, 기능, 패션 포인트, 옷의 일생)
- **주생활 — 주거 요소 탐구**(건축 자재·건축 구조·냉난방 설비·주택 형태·인테리어 28종, 기후별로 거르기) + **기후 적응 주택 카드**(공간, 기후, 설계 요소, 인테리어, 더 따져 볼 점)

카드는 ‘정답’이 아니라 **질문의 출발점**이에요. 각 카드의 ❓ 질문을 담아 궁금증 목록으로 가져갈 수 있습니다.

## 2. 들어 있는 자료

| 지표 | 단위 | 정의 |
|---|---|---|
| 연평균기온 | ℃ | 1년 동안의 평균 기온 |
| 연강수량 | mm/년 | 1년 동안 내린 비와 눈(녹인 물의 양)의 총량 |
| 폭염일수 | 일/년 | 1년 중 하루 최고기온이 33℃ 이상인 날의 수 |
| 열대야일수 | 일/년 | 1년 중 하루 최저기온이 25℃ 이상인 날의 수 |
| 5일 최다강수량 | mm | 1년 중 연속 5일 강수량 합계의 최댓값 |

- 지역: 용인시(기초 단위), 서울특별시(광역 단위) · 시나리오: SSP1-2.6(저탄소), SSP5-8.5(고탄소) · 기간: 현재(2000–2019), 전반기(2021–2040), 중반기(2041–2060), 후반기(2081–2100), 모두 20년 평균
- **출처·검증**: 기상청 기후정보포털 > 기후변화 시나리오 > 행정구역별 전망에서 **2026-10-15에 직접 조회해 40개 값(2지역 × 5지표 × 2시나리오 × 4기간)을 모두 대조**했습니다. 연평균기온·연강수량·폭염일수는 경기도·서울특별시 기후변화 전망보고서(2023) 값(폴더의 `용인서울_미래기후예시.csv`)과도 같고, PPT의 서울 열대야일수(96.1일)·5일 최다강수량(330.5·303.0·336.2mm)도 일치합니다.
- **'현재(2000–2019)'는 관측값이 아니라 기후모델이 과거를 재현한 값**(포털 설명: 과거재현 기간)이에요. 앱 화면에서도 학생에게 안내합니다. 실제 관측값은 기상자료개방포털에서 찾을 수 있어요.
- 포털 값은 기후모델 결과의 평균(앙상블 평균)이며, 2023년 1월 26일 갱신된 자료 기준입니다.
- 폭염일수·열대야일수 정의는 기상청 극한기후지수 정의(보도자료 2024-12-20)와 같습니다.

## 3. 자료·내용 고치기 (선생님용 파일 3개)

| 파일 | 고칠 수 있는 것 |
|---|---|
| `data.js` | 지역·지표·수치, 기본 시나리오, 지표 설명, 예측 버튼 한 칸 크기(`step`) |
| `rules.js` | 영역별 탐구 질문, 예시 질문, 조사할 곳, 주의 문구, **데이터로 세워 보는 가설** 규칙 |
| `explore.js` | 탐색 카드(작물·섬유·주거 요소)와 설계 카드 선택지 |

`index.html`, `style.css`, `js/` 폴더는 고칠 필요가 없습니다.

### 지역 추가 예 (`data.js`)

```js
regions: {
  "용인시": { ... },
  "서울특별시": { ... },
  "수원시": {
    temp:   { low: [현재, 전반기, 중반기, 후반기], high: [현재, 전반기, 중반기, 후반기] },
    precip: { low: [...], high: [...] },
    heat:   { low: [...], high: [...] },
  },
},
```

- 숫자는 단위·쉼표 없이 씁니다. 모르는 칸은 `null`.
- 그래프 색은 지역 4곳까지 구분됩니다.

### 가설 규칙 쓰는 법 (`rules.js`)

```js
{ when: "폭염일수 증가 >= 10", idea: "통기성·흡습속건 소재의 옷", why: "…" }
```

| 조건 | 뜻 |
|---|---|
| `"폭염일수 >= 30"` | 선택한 기간의 값이 30 이상 |
| `"폭염일수 증가 >= 10"` | 현재(2000–2019)보다 10 이상 증가 |
| `"연강수량 증가율 >= 5"` | 현재보다 5% 이상 증가 |
| `["조건1", "조건2"]` | 둘 다 만족 |

기준 숫자는 예시입니다. 학생 화면의 “기준을 넘지 않은 가설 보기”를 펼쳐 보며 조정하세요.

### 오타가 났을 때

앱 화면에 **“○○.js 파일 N번째 줄이나 그 바로 윗줄에 오타가 있는 것 같아요”** 라고 알려 줍니다. 줄 끝 쉼표, 따옴표 짝을 확인하세요.

## 4. 배포하기 (무료, 링크로 공유)

### 방법 A. GitHub Pages (권장 — 웹에서 바로 수정 가능)

1. github.com 가입·로그인 → **New repository** → 이름 예: `climate-living-lab`, **Public** → Create
2. **uploading an existing file** → 이 폴더 안의 **파일과 폴더 전체**(`index.html`, `site.html`, `qr.html`, `style.css`, `data.js`, `rules.js`, `explore.js`, `js/`, `assets/`, `data/`, `materials/`)를 끌어다 놓기 → **Commit changes**

수정: 저장소에서 파일 클릭 → 연필(✏) → 고친 뒤 Commit. 반영까지 몇 분 걸릴 수 있어요.

## 5. ‘나만의 웹’ 공유 방식

- **공유 링크**: 웹 내용이 링크 주소 안에 압축되어 들어갑니다. 서버에 저장되지 않고, 링크를 가진 사람은 누구나 볼 수 있어요. 패들렛·클래스룸에 올리면 됩니다. (배포된 주소에서 만들어야 다른 기기에서 열려요)
- **HTML 파일**: 인터넷 없이 열리는 한 파일짜리 웹입니다. Netlify Drop 등에 올리면 학생만의 주소가 생겨요.
- **코드 보기**: 웹을 이루는 HTML·CSS·JavaScript를 보여 주고 무엇을 바꾸면 되는지 설명합니다. 기술 영역(웹·프로그래밍) 연계 활동으로 쓸 수 있어요.
- 학생이 쓴 글은 모두 안전하게 처리되어 링크를 조작해도 스크립트가 실행되지 않습니다. 실명·학번은 넣지 않도록 화면에서 안내합니다.

## 7. 문제 해결

| 증상 | 해결 |
|---|---|
| “○○.js 파일을 읽지 못했어요” | 안내된 줄(또는 바로 윗줄)의 쉼표·따옴표 확인 |
| 고친 내용이 안 보임 | 몇 분 뒤 새로고침 |
| 가설이 하나도 안 나옴 | 중반기·후반기나 SSP5-8.5로 바꿔 보기, 또는 `rules.js` 기준 조정 |
| 공유 링크가 다른 기기에서 안 열림 | 컴퓨터 파일(file://)로 연 상태에서 만든 링크예요. 배포 주소에서 다시 만들기 |
| 오래된 태블릿에서 공유 링크가 안 열림 | HTML 파일로 공유 |
| Word 파일이 경고와 함께 열림 | 웹 형식으로 만든 .doc이라 생기는 안내예요. ‘예’를 누르면 열립니다. 한글(HWP)에서는 인쇄 → PDF를 권장 |
